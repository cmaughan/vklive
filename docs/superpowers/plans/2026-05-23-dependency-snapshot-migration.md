# Dependency Snapshot Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert VkLive/Rezonality into a self-contained monorepo-style application repo with owned libraries tracked as normal static library source, no git submodules, fast Ninja/ccache builds, and `compile_commands.json` available for Vim LSP.

**Architecture:** Snapshot owned libraries directly into the repo and make the root CMake project own the integration. Keep large standard dependencies in vcpkg manifest mode, use local ignored vcpkg bootstrapping for convenience, and reserve static snapshots for small or awkward third-party code already needed by the app.

**Tech Stack:** C++20, Objective-C++ for Metal, CMake presets, Ninja, ccache/sccache where available, vcpkg manifest mode, Python `do.py`, unittest.

---

## Decisions

- History preservation is not required for absorbed libraries.
- `zing`, `zest`, and `zep` become normal tracked source directories and build as static libraries.
- No `.gitmodules` file remains in the root repo.
- Existing local vcpkg checkouts can remain as ignored working copies, but fresh setup must not require a git submodule.
- `do.py` is the primary interface.
- `compile_commands.json` must be generated by the default configure path and exposed at the repository root for Vim LSP.

## Dependency Policy

| Dependency | New Owner | Strategy |
| --- | --- | --- |
| `zep` | VkLive repo | Snapshot as `libs/zep`, static target `Zep::Zep` |
| `zing` | VkLive repo | Snapshot as `libs/zing`, static target `Zing::Zing` |
| `zest` | VkLive repo | Snapshot as `libs/zest`, static target `Zest::Zest` |
| `libremidi` | Third party | Static snapshot under `libs/zing/libs/remidi` for this pass |
| `TinySoundFont` | Third party | Static snapshot under `libs/zing/libs/tsf` for this pass |
| `vcpkg` | External tool | Removed as submodule; use `VCPKG_ROOT`, local ignored `vcpkg/`, or ignored `.cache/vcpkg` |
| `rccp` | Third party | Remove if unused by current build; otherwise static snapshot |
| `nanovg_vulkan` | Third party | Remove if unused by current build; otherwise static snapshot |
| SDL2, assimp, fmt, glm, portaudio, spirv-cross, etc. | vcpkg | Root `vcpkg.json` manifest |
